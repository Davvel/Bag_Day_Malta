BAG DAY MALTA - FRIENDLY GAME WORDING FOR ALL AGES
Package 52 | Website v1.1.37 | Based on package 51 / v1.1.36

WHAT CHANGED
Reviewed game lessons, item explanations, destination captions, information
panels, menu/results wording and links for language that addresses the player
as a young child. The educational instructions now use clear, direct language
suitable for adults and children alike.

- 'ONE SMALL THING TO LEARN' becomes 'BEYOND THE BAGS'.
- 'Small batteries have their own home' becomes
  'Used batteries go in a battery bin'.
- Removed 'Ask a grown-up' from all player-facing lessons and item explanations.
- Battery column caption is now 'Battery collection'.
- Oil and paint headings state the destination directly: the Roadshow Truck.
- Bulky-item lessons explain booking with the Local Council directly.
- Information links describe their action: find a battery collection point,
  check the Roadshow schedule, or read official bulky collection information.
- The timing note is 'Choose a mode to start your one-minute round.'
- Useful practical instructions remain: closed oil containers, original
  labelled paint containers, council booking instructions and keeping button
  batteries out of reach of children. Safety information does not assume the
  player is a child.

The 86 static illustrations, item library, one-minute duration, round planning,
Try it / Play Classic choices, level-11 threshold, scoring and progress are
unchanged. The previous splash and native zoom behavior are preserved.

DEPLOY WEBSITE
1. Extract this ZIP.
2. Open COPY_TO_GITHUB. Copy everything INSIDE it into the root of your
   existing Bag Day WEBSITE repository, replacing matching files and merging
   folders. Do not copy the COPY_TO_GITHUB folder itself.
3. Keep your existing CNAME, .git folder, live configuration text files and
   repository configuration. This ZIP contains no CNAME.
4. In GitHub Desktop, review the changes and use this commit summary:
   Make game instructions friendly for all ages - v1.1.37
5. Click Commit to main, then Push origin. Wait for GitHub Pages to finish.
6. Open Bag Day online, refresh once, close and reopen it. Confirm Settings
   shows v1.1.37. Open Game online once to update its separate offline cache.
