BAG DAY MALTA - REALISTIC, LIGHTWEIGHT WASTE ARTWORK
Package 53 | Website v1.1.38 | Based on package 52 / v1.1.37

WHAT CHANGED
- All 86 waste items now use individually generated realistic static cutouts,
  replacing the simplified drawings with clearer silhouettes, material texture
  and natural colours. The labels still explain clean/empty/soiled conditions.
- Only small compressed WebP files are included for the new item artwork.
  Large source renders and preview boards are NOT included in the website.
- Images have transparent backgrounds and a maximum dimension of 192 pixels.
  Some detailed items use smaller dimensions to keep their file size down.
- New images are used for falling items, lesson examples and the results list.
- Versioned artwork is cached locally and reused without repeated downloads.
  The full compact set is included in the game's offline cache, preserving
  offline play after the new cache has installed successfully online.
- Game entry includes the release version so an old HTML copy cannot hide
  the new artwork. Game HTML is revalidated on navigation.
- Gameplay, the 86 item definitions, one-minute duration, scoring, progress,
  educational choice from level 11 and age-neutral wording are preserved.
- No item animation has been added. Existing game movement and controls remain.

IMAGE SIZE
See ARTWORK_NOTES.txt for measured total, average and largest image sizes.
The full ZIP also contains existing Home, REUSE and admin assets from previous
releases. Its size is not the size of the new waste image collection alone.

DEPLOY WEBSITE
1. Extract this ZIP.
2. Open COPY_TO_GITHUB. Copy everything INSIDE it into the root of your
   existing Bag Day WEBSITE repository, replacing matching files and merging
   folders. Do not copy the COPY_TO_GITHUB folder itself.
3. Keep your existing CNAME, .git folder, live configuration text files and
   repository configuration. This ZIP contains no CNAME.
4. In GitHub Desktop, review the changes and use this commit summary:
   Replace waste drawings with compact realistic artwork - v1.1.38
5. Click Commit to main, then Push origin. Wait for GitHub Pages to finish.
6. Open Bag Day online, refresh once, close and reopen it. Confirm Settings
   shows v1.1.38. Open Game online once so its separate image cache updates.

BACKEND
Frontend only. Do not run API deployment PowerShell scripts, database scripts,
SQL migrations or any backend commands for this release.

PHONE CHECKS
1. Start a classic round and check the new item pictures at their normal size.
   Check that the text remains readable and dragging/tapping works as before.
2. Play a level 11+ round. Check the lesson picture, Try it / Play Classic,
   special destination and result-list pictures. Reading remains untimed.
3. Inspect light/white items and dark items against the game cards. Labels
   remain useful for contents or conditions that pictures alone cannot prove.
4. After loading online and allowing the game cache to install, test offline.
5. Check Game entry from zoomed Home and Back to Home. Settings should still
   skip the splash and Home should show its minimum two-second splash.

This ZIP does not deploy anything to your live website or database.
