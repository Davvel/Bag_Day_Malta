BAG DAY MALTA - ZOOM-AWARE NAVIGATION
Package 47 | Website v1.1.32

WHAT CHANGED
- Native pinch zoom is available on Home, REUSE and the calendar.
- While zoomed in, drag to pan around the enlarged page. Home day swipes,
  calendar month swipes, settings pull gestures and advert swipes pause.
- Pinch back out to normal size to restore normal swipe navigation.
- Calendar: swipe left for the next month, right for the previous month.
  The existing Today-to-30-days date range still applies. Arrow buttons remain.
- REUSE keeps its layout size while zoomed, including open item panels.
  Opening the keyboard at normal zoom still adjusts the available height.
- Multi-finger gestures cancel pending swipes without selecting a day/item.
- Advert rotation and Home helper animations pause while zoomed.
- There is NO automatic zoom-out.

DEPLOY WEBSITE
1. Extract this ZIP.
2. Open COPY_TO_GITHUB. Copy everything INSIDE it into the root of your
   existing Bag Day WEBSITE repository, replacing matching files and merging
   folders. Do not copy the COPY_TO_GITHUB folder itself.
3. Keep your existing CNAME, .git folder and repository configuration.
   This ZIP contains no CNAME.
4. In GitHub Desktop, review the changes, enter this commit summary:
   Add zoom-aware gestures and calendar month swipes - v1.1.32
5. Click Commit to main, then Push origin. Wait for GitHub Pages to finish.
6. Close and reopen Bag Day. Check Settings shows v1.1.32.
   If it still shows the older version, refresh once while online and reopen.

BACKEND
This release is entirely a website update. No API deployment, PowerShell
commands, database scripts or migrations are needed for the zoom changes.
It preserves the existing v1.1.31 website features and current API configuration.

TRY IT ON YOUR PHONE
1. Home: pinch over the bag to enlarge it. Drag left, right, up and down.
   The displayed day should stay unchanged while panning.
2. Pinch back out. Swipe left/right to move between days again.
3. Open the calendar. Swipe left for the next available month, then right
   to return. It should stop at the current 30-day date-range boundaries.
4. Zoom the calendar and pan: the month should stay unchanged.
   Pinch back out; month swipes should work again. Date taps and arrows remain.
5. REUSE: zoom the item list and open item details. Pan around enlarged text.
   The page and panels should not shrink or chase your finger.
6. Start a swipe, then place a second finger to pinch. It should cancel the
   pending swipe without changing the day/month or opening a touched item.
7. Leave the page zoomed for more than 15 seconds: it should stay zoomed.

The ZIP has not deployed or changed your live website or database.
