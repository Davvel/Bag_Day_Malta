BAG DAY MALTA - SPLASH TIMING AND MORE MANUAL ICONS
Package 49 | Website v1.1.34 | Based on package 48 / v1.1.33

WHAT CHANGED
- Opening Settings skips the splash entirely, including the artwork wait,
  minimum display time and splash fade. Settings keeps its normal-zoom entry.
- Opening Home shows the splash for at least two seconds before fading out,
  even when images are already cached. If artwork needs longer, the splash
  waits for readiness within the existing loading timeout. The two-second
  minimum also applies with reduced-motion enabled; the fade is then skipped.
- REUSE Manual Select now offers 397 icons instead of 208: 189 added choices
  across the existing categories, including electronics, kitchen, clothing,
  garden/tools, toys, crafts, sports, music, pets, mobility and household items.
- Existing icons remain available. Additional search synonyms help find items
  such as a WiFi router, lunch box, chess set, keyboard, wheelchair or sewing.
- The compact icon picker, automatic close after choosing, pasted emoji and
  Auto Find behavior are retained. The additions need no backend change.
- Existing native zoom/panning and calendar protections are preserved.

DEPLOY WEBSITE
1. Extract this ZIP.
2. Open COPY_TO_GITHUB. Copy everything INSIDE it into the root of your
   existing Bag Day WEBSITE repository, replacing matching files and merging
   folders. Do not copy the COPY_TO_GITHUB folder itself.
3. Keep your existing CNAME, .git folder, live configuration text files and
   repository configuration. This ZIP contains no CNAME.
4. In GitHub Desktop, review the changes and use this commit summary:
   Skip Settings splash, show Home splash for 2s and expand icons - v1.1.34
5. Click Commit to main, then Push origin. Wait for GitHub Pages to finish.
6. Close and reopen Bag Day. Check Settings shows v1.1.34.
   If it still shows an older version, refresh once while online and reopen.

BACKEND
Frontend only. Do not run API deployment PowerShell scripts, database scripts,
SQL migrations or any backend commands for this release.

PHONE CHECKS
1. Open or refresh Home with cached images: the splash stays for at least
   two seconds before fading. It should not disappear immediately.
2. Open Settings: no splash should appear. Close it or press mobile Back.
3. From magnified Home, open Settings: check normal zoom on entry and the
   remembered Home zoom on return, as in v1.1.33.
4. In REUSE, Give or edit an item, then Manual Select (or Edit Icon first).
   Browse the larger categories and search for 'router', 'chess', 'wheelchair'
   and 'lunch box'. Pick an icon: it appears before the title and the picker
   collapses as before. Check a pasted emoji still works too.
5. Check Home/calendar zoomed panning and normal day/month swipes still work.
