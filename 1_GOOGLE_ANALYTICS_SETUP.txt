GOOGLE ANALYTICS - REQUIRED ONE-TIME SETUP
Do this in your existing GA4 property; the ZIP cannot change your GA settings.
Open Admin, then Data display > Custom definitions. Add a dimension using:
Dimension name: Sponsor Name
Scope: Event
Event parameter: sponsor_name
Save it. Keep your existing Sponsor ID dimension.

For a sponsor report, open a Free form exploration. Import Sponsor Name,
Sponsor ID and Event name as dimensions; import Event count as the metric.
Use Sponsor Name and Sponsor ID as rows and Event count as the value.
Filter Event name to exactly sponsor_impression for impressions.
Use a separate tab filtered to sponsor_click for clicks; choose the date range.
The name is the registered SponsorName, not the advert headline.

New names can take 24-48 hours to appear after setup and incoming events.
Past events that only contain an ID cannot gain a name retrospectively.
Existing impressions remain consent-gated, require at least 50% visibility
for one second, and count once per sponsor/slot/locality per page load.
They are measured advert views, not total unfiltered page views.
Community adverts continue to use their separate community events.
