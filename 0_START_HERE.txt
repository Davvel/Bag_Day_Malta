Bag Day Malta frontend v1.1.144 — Editable locality map starting points

INSTALL BACKEND v1.1.39 FIRST, using the companion backend ZIP.
Run these three commands in PowerShell from the extracted backend folder,
one at a time. Continue only after each succeeds:
.\1_Check_and_Backup_API.ps1
.\2_Deploy_API.ps1
.\3_Verify_API.ps1

Then copy everything inside 2_WEBSITE/COPY_TO_GITHUB into the website
repository, replacing matching files. Commit and publish as usual.
Reload the Admin tab and any open notice editors after deploying both parts.

Admin > Localities > Edit now shows the effective latitude, longitude and
source. Use Adjust on map to tap or drag the starting pin, or type coordinates.
Use bundled starting point restores the default for the entered locality name.
Unknown names fall back to the general Malta starting point.
Only Save locality persists changes. Cancel discards them.
Changing a locality centre does not change existing notice pins.
The next loaded notice editor uses the saved locality centre.

No new API key, address lookup, billing service or database migration is added.
The backend installer retains the existing additive location migration.
Step 4 (sponsor exporter) is not needed for this update.

Validation: automated frontend and backend checks are included.
Interactive browser/map visual verification was not available in this environment.
