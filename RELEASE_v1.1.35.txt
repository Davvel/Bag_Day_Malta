BAG DAY MALTA - OLD SETTINGS SPLASH CACHE FIX
Package 50 | Website v1.1.35 | Based on package 49 / v1.1.34

WHAT CHANGED
The old version number reported when opening Settings suggests an older
Settings document was being reused. Settings previously used the same URL
across releases, separately from the normal Home page.

- Settings now opens with a release-specific URL to bypass older query copies.
- Page navigation revalidates HTML instead of trusting an old HTTP cache copy.
- Offline Settings uses the current release's canonical Home shell, rather
  than an older query-specific document or another release's cache.
- Splash hiding for Settings is also declared directly in the document head,
  before the external startup script and styles finish loading.
- Home retains its two-second minimum splash display before fading.
- All 397 REUSE manual icons and the existing zoom behavior are preserved.
