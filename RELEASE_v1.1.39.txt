BAG DAY MALTA - CLASSIC-FIRST ROUNDS AND COMPACT GAME INTRODUCTION
Package 54 | Website v1.1.39 | Based on package 53 / v1.1.38

WHAT CHANGED
- Levels 1-10 always use classic Organic / Mixed / Recyclables bags.
- Above level 10, every new round (Play, replay, or Play Next Level) draws a
  fresh random mode: 60% Classic, 40% special. This is a probability for each
  round, not a guaranteed six-out-of-ten quota or a daily selection.
- Special destinations have equal chances: Battery bin, Roadshow Truck and
  Bulky collection each have a 13 1/3% overall chance.
- Roadshow chooses oil or paint equally; bulky chooses its six lessons equally.
- Classic rounds start directly. Special rounds show their introduction, with
  Try it or Play Classic. Reading does not use any of the 60-second round.
- Removed the three inactive destination labels from the introduction.
- Smaller illustration and spacing; Try it / Play Classic appear side by side.
- Additional guidance is available under More disposal information, collapsed
  each time. Short screens or enlarged text can still scroll the introduction.
- Existing artwork, scoring, progress and one-minute duration are preserved.

DEPLOY WEBSITE
1. Extract this ZIP.
2. Open COPY_TO_GITHUB. Copy everything INSIDE it into the root of your
   existing Bag Day WEBSITE repository, replacing matching files and merging
   folders. Do not copy the COPY_TO_GITHUB folder itself.
3. Keep your existing CNAME, .git folder, live configuration text files and
   repository configuration. This ZIP contains no CNAME.
4. In GitHub Desktop use this commit summary:
   Add classic-first random rounds and compact game intro - v1.1.39
5. Click Commit to main, then Push origin. Wait for GitHub Pages to finish.
6. Open Bag Day online, refresh once, close and reopen it. Confirm Settings
   shows v1.1.39. Open Game online once to update its separate offline cache.
