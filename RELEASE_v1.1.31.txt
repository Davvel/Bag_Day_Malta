BAG DAY MALTA - CUSTOM EMOJI TITLE ICONS
Frontend v1.1.31 - Package 46

In the item icon picker, search by name or paste an emoji from your clipboard
or keyboard. A detected emoji appears with a Use this emoji button, even when
it is absent from the built-in catalogue. Tap to select it: the icon appears
before the title and the picker closes. If you paste several emojis, choose
one. One detected emoji can also be confirmed with Enter.
Your icon is retained when saving and editing and appears in item lists and
item details. Existing manual search, Auto Find and Clear icon remain available.

DEPLOY BACKEND FIRST
This release needs backend v1.1.19, included in 1_BACKEND. Follow its instructions
and run all three numbered scripts before publishing this website update.
No new database fields are needed for this feature.

DEPLOY WEBSITE
1. Copy everything INSIDE COPY_TO_GITHUB into the root of your existing
   website repository, replacing matching files and merging folders.
2. Keep your existing CNAME and .git folder. This ZIP contains no CNAME.
3. Commit and push using GitHub Desktop, then wait for GitHub Pages.
4. Close and reopen Bag Day. Check Settings shows v1.1.31.

All changes from website v1.1.30 are included, including single-choice Colour
and Material dropdowns, aligned purchase fields and the Free Stuff button.
Only the contents of COPY_TO_GITHUB belong in your website repository.
